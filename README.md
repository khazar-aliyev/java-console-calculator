# Java Console Calculator

A user-friendly, interactive console application built in Java that performs basic arithmetic operations and power calculations.

This project showcases modern **Java 14+ Enhanced Switch Expressions** (`->` arrow syntax), input validation, and flag-based error handling.

## Features
- **Supported Operations:**
  - Addition (`+`)
  - Subtraction (`-`)
  - Multiplication (`*`)
  - Division (`/`)
  - Exponentiation / Power (`^`)
- **Safe Math Execution:**
  - Prevents division by zero with custom error messaging.
  - Catches invalid operator inputs gracefully using boolean flags to avoid displaying false results (`0.0`).
- **Modern Syntax:** Clean structure using arrow switch expressions.
